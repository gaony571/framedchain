# Changelog (dates UTC)

framedchain was called framespace up to version 0.3.3; entries below 0.4.0 use the old name.

## Unreleased (documentation only)

- Docstring corrections, with `docs/API.md` regenerated: `distance` names its 128 default starts as the identity and
  127 random rotations; `reduced` says that the half-width of 20 was chosen after the bias check by a rule fixed in a
  later record (S2 Text 2 of the paper); `ensemble` and the README map ratio to κ and B_Q to B_P′ of the paper. No
  code changed.
- Docstrings, comments and the README in the paper's terms, with `docs/API.md` regenerated: the README shows Fig 1 as
  redrawn for the paper (`docs/framed_chains.png`) with the paper's caption; "normalized distance D̂" for
  "mean-normalized", "intersection of near-optimal alignments" for "joint gate", "factorial comparison" for "factorial
  design", the population counterpart of Δ² as in the paper; ratio = 1 lies inside the crossing band, between the near
  and far limits; the general lemma in `rulers` gives a pseudometric, and a metric under the paper's conditions; tied
  values in `dynamics_similarity` get distinct ranks in sort order; D_{w,ℓ} is marked as not used in the paper; the
  cis Cα–Cα distance is no longer quoted; `tests/test_rulers.py` names its source as `framespace_wip/tests_stage0` of
  framedchain-paper; the date of 0.4.1 is given in UTC (2026-10-27). No code changed.
- American spelling in two more docstrings ("majorization" in `rulers`, "replicates" in `ensemble`) and
  `docs/API.md` regenerated; the README no longer says the companion repository is to be made public with the paper
  (both repositories become public before the paper is submitted); this file lists sections newest first. No code changed.
- Docstring corrections, with `docs/API.md` regenerated: `rulers.tm_forms` names both square-root forms (D_TM and
  D_TM/√L̄) as metrics at fixed d₀; the `reduced` module and the README give the initial band half-width of 20 used for
  the pairs of the comparison across sequences with TM-score below 0.3; `Alignment` has a docstring; the names of the
  paper's analyses in `parts`, `ensemble`, `rulers` and the README follow the paper. No code changed.

## 0.4.2 (2026-11-01)

- `is_break` and `BREAK_MIN` (4.2 Å): flags edges long enough to span a gap in the chain, the criterion of the
  paper's chain-break check. The PDB reader still joins residues in file order; use `is_break` on its output.
- No computation changed: apart from docstrings, the code of every existing function is identical to 0.4.1 (syntax
  trees compared module by module); the 47 tests (46 + one for `is_break`) pass and the quick-start values are the same.
- Documentation: American spelling in docstrings, comments, the README and this file, `docs/API.md` regenerated;
  the README shows Fig 1 of the paper (`docs/framed_chains.png`) and gives BibTeX entries; "pre-specified" replaces
  "pre-registered", as in the paper; `CITATION.cff` gives the author's affiliation and ORCID and an abstract.

## Repository history (2026-10-31)

- The commit messages, written in Korean until 2026-10-29, were translated into English by rewriting the history.
  No file, author or date changed (each commit keeps its file tree hash, and the tags keep their messages and dates),
  but every commit identifier changed again. Tag `v0.2.0` is now commit `5e4fdf9` (`866995c` from 2026-10-26, `efcdd42`
  before; file tree `6db30c0` throughout). The full map is in `docs/PROVENANCE.md` of the framedchain-paper repository.
- The Korean translation of the README (`README.ko.md`) was removed; the README is in English only.

## 0.4.1 (2026-10-27)

- Documentation only: the paper's title, *Comparing protein conformational ensembles across sequences and lengths* (in preparation), and its
  terms (shared-bond and unshared-bond parts) in the README, README.ko and CITATION.cff. No code change.

## 0.4.0 (2026-10-26)

- Renamed from framespace to framedchain: distribution name, import name (`import framedchain as fc`) and repository
  (github.com/gaony571/framedchain; GitHub redirects the old address). `import framespace` no longer works. No
  computation changed (the 46 tests and the quick-start output are identical).
- Descriptions follow the paper's abstract.

## 0.3.3 (2026-10-26)

- `align` accepts numpy arrays and mixed inputs (y and starts follow the dtype and device of x), like the other
  high-level functions. Results for tensor inputs are unchanged (checked against 0.2.0 on random inputs).
- Docstrings for `distance`, `as_tensor`, `sq_norm` and the quaternion helpers; ASCII-only runtime messages.
- `tests/test_usage.py` (numpy and mixed inputs, PDB files on disk, batching with zero padding, ensembles of
  different lengths); 46 tests.
- `examples/quickstart.py`, `docs/API.md` (generated by `tools/make_api_doc.py`), install, performance and
  reproducibility notes in the README.
- Repository history: on 2026-10-26 the author name in the history was unified and trailer lines were removed
  from the commit messages. This changed every commit identifier but no file or date (each commit keeps its file
  tree hash). Tag `v0.2.0` became commit `866995c` (formerly `efcdd42`; file tree `6db30c0` in both; see the note of 2026-10-31 for the current identifier). The full map is in `docs/PROVENANCE.md` of the
  framedchain-paper repository.

## 0.3.2 (2026-10-26)

- Docstrings, comments and messages translated into English; code unchanged (AST comparison against 0.3.1).
- License metadata as an SPDX expression (`license = "MIT"`, `license-files`).

## 0.3.1 (2026-10-26)

- `parts.near_optimal_alignments` and `ensemble.aligned_energy_stats` (computations of the paper).
- MIT license, `CITATION.cff`, English README.

## 0.3.0 (2026-10-25)

- Computations and estimators fixed in the paper: `reduced` (mean-point starts, banded DP, `pair_scores`),
  `ensemble` (energy statistic, components, incomplete U-statistic, η₊, spread profiles, r_dyn), `parts`
  (matched/gap split, normalized distance), `rulers` (D_{w,ℓ}, D_TM).

## 0.2.0 (2026-10-16)

- Ensemble W₂ by exact optimal transport (`transport`). This is the version used in the paper's runs (tag `v0.2.0`,
  commit `5e4fdf9`).
