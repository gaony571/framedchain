# Changelog (dates UTC)

framedchain was called framespace up to version 0.3.3; entries below 0.4.0 use the old name.

## Repository history (2026-10-31)

- The commit messages, written in Korean until 2026-10-29, were translated into English by rewriting the history.
  No file, author or date changed (each commit keeps its file tree hash, and the tags keep their messages and dates),
  but every commit identifier changed again. Tag `v0.2.0` is now commit `5e4fdf9` (`866995c` from 2026-10-26, `efcdd42`
  before; file tree `6db30c0` throughout). The full map is in `docs/PROVENANCE.md` of the framedchain-paper repository.

## 0.4.1 (2026-10-28)

- Documentation only: the paper's title, *Comparing protein conformational ensembles across sequences and lengths* (in preparation), and its
  terms (shared-bond and unshared-bond parts) in the README, README.ko and CITATION.cff. No code change.

## 0.4.0 (2026-10-26)

- Renamed from framespace to framedchain: distribution name, import name (`import framedchain as fc`) and repository
  (github.com/gaony571/framedchain; GitHub redirects the old address). `import framespace` no longer works. No
  computation changed (the 46 tests and the quick-start output are identical).
- Descriptions follow the paper's abstract.

## 0.3.3 (2026-10-26)

- `align` accepts numpy arrays and mixed inputs (y and starts follow the dtype and device of x), like the other
  high-level functions. Results for tensor inputs are unchanged (checked against 0.2.0 on random inputs).
- Docstrings for `distance`, `as_tensor`, `sq_norm` and the quaternion helpers; ASCII-only runtime messages.
- `tests/test_usage.py` (numpy and mixed inputs, PDB files on disk, batching with zero padding, ensembles of
  different lengths); 46 tests.
- `examples/quickstart.py`, `docs/API.md` (generated by `tools/make_api_doc.py`), install, performance and
  reproducibility notes in the README.
- Repository history: on 2026-10-26 the author name in the history was unified and trailer lines were removed
  from the commit messages. This changed every commit identifier but no file or date (each commit keeps its file
  tree hash). Tag `v0.2.0` became commit `866995c` (formerly `efcdd42`; file tree `6db30c0` in both; see the note of 2026-10-31 for the current identifier). The full map is in `docs/PROVENANCE.md` of the
  framedchain-paper repository.

## 0.3.2 (2026-10-26)

- Docstrings, comments and messages translated into English; code unchanged (AST comparison against 0.3.1).
- Licence metadata as an SPDX expression (`license = "MIT"`, `license-files`).

## 0.3.1 (2026-10-26)

- `parts.near_optimal_alignments` and `ensemble.aligned_energy_stats` (computations of the paper).
- MIT licence, `CITATION.cff`, English README.

## 0.3.0 (2026-10-25)

- Computations and estimators fixed in the paper: `reduced` (mean-point starts, banded DP, `pair_scores`),
  `ensemble` (energy statistic, components, incomplete U-statistic, η₊, spread profiles, r_dyn), `parts`
  (matched/gap split, normalised distance), `rulers` (D_{w,ℓ}, D_TM).

## 0.2.0 (2026-10-16)

- Ensemble W₂ by exact optimal transport (`transport`). This is the version used in the paper's runs (tag `v0.2.0`,
  commit `5e4fdf9`).
